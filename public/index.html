Synora

Server

Dashboard /viewer

All client feeds: tile grid, synced combined view, 3D room view, recordings and virtual webcam control. Open this on the PC.

Print room tags /markers

Printable ArUco tags (150 mm, one per A4 sheet). Mount around the room; tag 0 is the room origin.

Client

Client /client

Streams this device's camera to the dashboard. Open on each client (the QR code in the server console points here).

Camera calibration /calibrate

One-time per client lens: print the ChArUco board, capture ~15 views, save intrinsics. Marker distances go from ~5% to sub-1% error.

XR client /xr-client

Positioning and mapping from ARCore: its world tracking carries the pose between tag sightings, its depth replaces the depth model entirely. Does not stream video. Android + ARCore only.

WebXR probe /xr-probe

Asks this device what WebXR actually grants — world tracking, camera access, depth — and measures how far its tracking drifts when you walk a loop. A measurement, not a feature.

On-screen tag /digital

Shows a room tag on this screen at true physical size instead of printing — calibrate the screen once with a credit card.
